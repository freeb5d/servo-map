# ServoMap

Australian fuel prices on one map. ServoMap reads each state's official fuel-price feed, keeps a
normalised copy at the edge, and shows it on the web and on iPhone.

- **Web:** [www.servo-map.com](https://www.servo-map.com)
- **iPhone:** in TestFlight (internal testing), not yet on the App Store
- **Coverage:** New South Wales and Western Australia today; other states as their feeds are connected

## What is in this repository

```
apps/ios/                SwiftUI app for iOS 27: map, trends, saved stations, fill-up log,
                         widgets, Siri shortcut. Xcode project generated by xcodegen.
packages/design-tokens/  The design system's values (colour, type, spacing, radius, motion).
                         Generates the web Tailwind theme and the iOS Swift tokens.
packages/shared/         Types and reference tables (fuel types, brand families) shared by
                         web, worker and, through generated Swift, the iOS app.
packages/worker/         Read-only Cloudflare Worker (Hono) serving the REST API from KV.
packages/web/            Next.js site: map, suburb and station pages, trends, saved.
scripts/fetch-data.ts    The ingest run by GitHub Actions every 15 minutes.
design/app-icon/         The fuel-gauge mark: one generator for the favicon, the web mark
                         and the iOS app icon.
docs/                    API contract, design system, decisions, and agent rule docs.
```

## Develop

Needs Node 22 and pnpm 10. The iOS app needs Xcode 27 and xcodegen.

```bash
pnpm install
pnpm --filter @servo-map/shared build
pnpm dev:worker          # API on :8787
pnpm dev:web             # site on :3000
```

Checks, as CI runs them:

```bash
pnpm -r typecheck && pnpm -r lint && pnpm -r test
pnpm --filter @servo-map/web build
```

iOS:

```bash
cd apps/ios
xcodegen generate
xcodebuild test -project ServoMap.xcodeproj -scheme ServoMap -destination 'platform=iOS Simulator,name=iPhone 17'
```

## Design

A Japanese-minimal system (素): paper, sumi ink, and price tiers as the only colour. Values live in
`packages/design-tokens`; web and iOS are generated from it, so neither hardcodes a colour or size.
See [`docs/design/system.md`](docs/design/system.md) and the decisions in
[`docs/decisions`](docs/decisions).

## Releases

[release-please](https://github.com/googleapis/release-please) cuts every release from
Conventional Commits, as `misoto22-release-bot`:

- **Web and worker** share one version, tagged `vX.Y.Z`. Merging to `main` deploys both.
- **iOS** has its own version, tagged `ios-vX.Y.Z` and written into
  `apps/ios/Config/Version.xcconfig`. It stays `0.x` until the App Store launch.
- **TestFlight:** `apps/ios/scripts/beta.sh` runs fastlane with the App Store Connect key from
  1Password. See [`docs/claude/deployment.md`](docs/claude/deployment.md).

## Data

Prices come from government reporting schemes and can lag the bowser. ServoMap never estimates a
price. Data sources and methodology: [servo-map.com/about](https://www.servo-map.com/about).
Privacy: [servo-map.com/privacy](https://www.servo-map.com/privacy).
