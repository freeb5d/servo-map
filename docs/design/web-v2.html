ServoMap Web v2 · 页面重构提案
ServoMap Web · v2 提案 · 第二版

先给结论，再给清单，地图只负责「在哪」。

风格不变，页面逻辑重做。这一版按你的反馈补了三块：每个站点都显示品牌，筛选面板做全，趋势页从一张图扩展成九个模块。所有数字来自现有 API 的真实结构；截至 9 月 29 日，NSW 的 U91 均价约 240，是 90 天内的最高点。

改了什么

加黑框的是这一版新增的内容。

处处显示品牌

旧：品牌只在列表里是一行小字，地图上完全没有

每个站点带一枚品牌印章（三字母缩写），地图价签、账本、详情、收藏里都一样。89 个原始品牌名先归并成品牌族，再显示。

完整筛选

旧：只有品牌多选
  • 快捷筛选条：5 km 内、只看便宜、6 小时内更新、大品牌、隐藏会员站
  • 面板：价格分布直方图加上限、距离、新鲜度、按品牌族多选（带站数和均价）、包含/排除模式、「同时有柴油」
  • 筛选写进网址，可以分享；可以存成预设

趋势九个模块

旧：一张 30 天折线图
  • 结论、周期位置、今日均价、今日价差
  • 90 天走势（诚实标出数据缺口）
  • 五种燃油对比、品牌排行、郊区排行
  • 星期规律、「选对时间和站点一年能省多少」计算器

固定顶栏取代浮层

旧：Logo、燃油、搜索、主题、新鲜度、定位提示各自浮在地图上

一条纸面顶栏装下全部控件，地图上只留缩放和图例。

结论先行、账本式列表

旧：「Nearby Stations · Showing 335」

先回答「附近最低多少、现在该不该加」，再按价格编号列出。超过 24 小时的价格沉到分隔线下。

详情抽屉、纸质价签

旧：详情替换列表；地图上是彩色裸字

详情从右侧滑出，列表不动。地图价签是 品牌｜价格 ■ 的纸签。

品牌：怎么显示、怎么归并

用自己的品牌印章，不直接用各家 logo：风格统一，小尺寸下更好认，也避开商标授权问题。以后要换成官方 logo，只需要换掉印章组件。

旧 · 彩色裸字，无品牌
新 · 品牌｜价格 ■ 纸签选中时整签反转为墨底
印章品牌族分组归并的原始名称（来自 /brands）

品牌族映射表放在 @servo-map/shared，Web、iOS 和 ingest 共用同一份。没匹配到的名称统一归入「独立站」，并在 ingest 日志里列出，方便补充。

桌面

1200 宽。窄屏时横向滚动查看。

地图 · 默认结论 → 快捷筛选 → 账本 → 地图
地图 · 筛选面板直方图显示当前价格分布，拖动上限时底部计数实时变化
地图 · 选中站点右侧抽屉，列表保留选中态
趋势九个模块，全部来自 /trends 和 /stations
郊区页（SEO）文档式排版，可被索引

手机

顶部固定搜索和燃油，底部标签栏与 iOS 一致；筛选和详情用全高抽屉。

实现范围

不需要新后端；有两项计算建议之后移到 worker 预先算好。

路由

/ 地图，/trends 趋势，/saved 收藏。筛选状态写进查询参数（?fuel=U91&max=230&brands=metro,costco），可以直接分享。SEO 页地址不变。

数据

  • 周期、走势、星期规律、燃油对比：/trends
  • 品牌排行、郊区排行、价差、直方图：由 /stations 当前结果在前端聚合
  • 整州范围的品牌和郊区排行数据量大，建议下一步由 ingest cron 预先算好写入 KV

不做

营业时间、24 小时、洗车、折扣券这几项 API 里没有数据，筛选里不放。加油记录只在 iOS 做。到价提醒和顺路加油需要新后端，另开决策。
